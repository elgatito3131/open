    About Data Structures Workshop

    Data Structures Workshop

    A collection of Java experiments for seeing how data structures change, one operation at a time.

    Edit the initial values and instructions, then press Play or Next. Reset keeps your inputs. Show code places the Java source beside the visualization.

    The Java program performs the operations. The browser only positions and displays its recorded snapshots.
