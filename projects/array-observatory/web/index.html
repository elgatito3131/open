    About Array Observatory

    Array Observatory

    An independent Java project for exploring generic dynamic arrays, operation costs, and execution traces.

    Includes an original array engine, trace format, local HTTP server, and browser interface. Build chapters connect the source to working experiments.

    Built with AI assistance. No coursework prompts, scaffolds, or solution files are included.
