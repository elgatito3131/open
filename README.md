# open

Small, runnable software projects with visible internals. Each project connects three ways of understanding a program: **build it, follow its execution, and read its source**.

## Start here: Array Observatory

A Java dynamic-array experiment with a 90s desktop interface. Edit a sequence of operations, watch storage grow and values move, then jump to the Java line behind a frame. The browser displays snapshots generated by the Java engine.

![Array Observatory](projects/array-observatory/docs/preview.png)

```sh
cd projects/array-observatory
./test.sh
./run.sh
```

Requires a JDK supporting Java 17 or later and a POSIX shell. Open <http://127.0.0.1:4196> after starting the server. No downloaded Java dependencies are required.

## Checks

The GitHub workflow compiles and checks the Java project with Java 17 and 21. The same engine checks run locally with `./test.sh` inside the project directory. A successful new implementation does not establish historical deployment, customer, institutional, or contribution claims.
